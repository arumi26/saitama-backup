# Initial Disclosure Template

Use this for first contact with a private/personal recipient. One bug per message.

```
Halo, nama saya [Nanwasa] dan saya menemukan kerentanan pada domain/subdomain [URL/repo]

Vulnerability :
[Short name]

Affected URL :
[File path + function + lines]

Severity :
[HIGH / MEDIUM-HIGH / CRITICAL]

Impact :
[1-2 sentence user-facing impact]

Thank You

Regards,
[Nama]
```

# Full Report Template

Use this only after recipient asks for details.

```
Halo, nama saya [Nanwasa] dan saya menemukan kerentanan pada domain/subdomain [URL/repo]

Vulnerability :
[Name]

Affected URL :
[Exact file path + function + lines]

Severity :
[CVSS-style or HIGH/MEDIUM/LOW]

Description :
[Technical explanation]

Impact :
[User/protocol consequences]

Remediation :
[Concrete fix, with code if possible]

References :
- [Repo/file links]

Proof of Concept :
[Path to PoC + how to run + test status]

Thank You

Regards,
[Nama]
```
