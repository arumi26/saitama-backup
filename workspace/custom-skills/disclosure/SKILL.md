# Disclosure & Triage

## Where it pays
Coordinated disclosure etiquette + triage comms.

## Signals
A submitted/ready finding.

## Methodology
Report via official channel; never public first; follow policy/timeline; respond precisely to triage; retest fixes; no program → security.txt/VDP/CERT.

## Validation gate
Disclosed per policy; outcome logged.

## Impact & chains
closes the loop; feeds learning.
