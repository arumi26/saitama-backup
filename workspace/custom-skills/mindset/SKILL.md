# Hunter Mindset
1. Understand before you attack — bugs live where developer assumptions break.
2. Follow the data, not the tool output.
3. Chain, don't settle — "what does this unlock?"
4. Automate recon, hand-hunt logic.
5. Depth beats breadth on good targets.
6. Notes/memory are leverage — patterns emerge.
7. Response differentials are signals.
8. Be a good citizen — scope & rate limits keep you (and the agent) unbanned.
9. Novelty pays — new features, odd content-types, non-browser clients, binaries.
10. Finish what you start — a half-proven bug is unpaid.
